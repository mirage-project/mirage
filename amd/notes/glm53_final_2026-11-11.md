# GLM-5.3 (zai-org/GLM-5.3, FP8, TP 8, no EP) on 8x MI355X: final state 2026-11-11

## Setup

- Libraries: `TREE=<this tree> DLIB=<out> bash amd/serving/glm53/build_glm53_libs.sh "1 2 4 8 16 32 64"` - 21 libraries, kinds
  `g53full` (DSA layer with its own indexer) / `g53shared` (DSA layer reusing the previous list) / `g53dense` (the 3 dense layers)
  x T 1..64; one kernel per layer, the flags in `glm53_layers.G53_FLAGS`.
- Server: `MPK_G53=run MPK_G53_DLIB=<out> G53_TREE=<this tree> amd/serving/glm53/srv_run_glm53.sh NAME` in
  `lmsysorg/sglang-rocm:v0.5.22-rocm10-mi35x-20261019` (the hook `amd/serving/glm53/sglang_glm53.py` replaces each decode layer of
  SGLang's DeepseekV2 model by our kernel; without `MPK_G53=run` the same script runs SGLang alone). Plain decode, no MTP,
  256 greedy tokens per request, the prompts of `bs_client.py` (contexts 12..268 tokens).
- vLLM: `amd/serving/glm/srv_run_vllm.sh NAME` with TP 8, in `vllm/vllm-openai-rocm:v0.32.0` (AITER, fp8 KV cache), the same
  prompts (`bs_client_oai.py`).
- Ours and SGLang in one session on one box, vLLM in a separate run on the same box.

## Flags

Set by every GLM-5.3 library (`glm53_layers.G53_FLAGS`), kept as flags because the GLM-5.3-Flash libraries built from the same
headers leave them off: `STATIC_ARS_LAND_MIN_T=1`, `STATIC_RBLK_PAR=1`, `STATIC_GME_W13DB=1`, `STATIC_GME_W2R=128`,
`STATIC_GME_W2XQ=2`, `STATIC_GME_CUPOST=1` (and env `MPK_ARS_LAND_MIN_T=1`).

Plain code (were flags while measured): `STATIC_QA_POLLALL`, `STATIC_SA_EARLYKT`, `STATIC_GME_XS2`; the sparse attention reading
`req_to_token` itself in full layers, the SPREAD split combine, the o absorb in token tiles of 16 from T 32, fp8 attention gemms,
the add + RMSNorm in the all-reduce senders (both all-reduces), the reduce-scatter all-reduce from T 16, store gemms counted in 8
row groups.

Removed with their code: `STATIC_MN_POLLALL`, `STATIC_SA_PF` (no gain in the server), the FLAG / VC split combines, the separate
`glm53_add_rmsnorm` task (folded into `allreduce_send`), several layers per kernel (bit-identical, but 10-15 % slower: 2 layers
spill 132 VGPRs; non-inlined tasks cost ~50 us per layer), the land-stamp diagnosis and the harness's grid override.

Check: the stripped `.s` (`.loc` / `.file` / `.ident` / `.cfi_` / comments removed) of all 21 libraries before and after the
cleanup are equal but for the `__hip_cuid` symbol and task-node ids one lower (an unused tensor removed).

## What each kept change bought (layer-pair harness / in-session server A B A B)

- W2 items from 8 per-XCD pools in slot order (`W2XQ`): pair T 16 / 32 / 64 -10.5 / -10.5 / -12.3 us.
- The CU-unit path counting each W13 unit right after its stores (`CUPOST`): server bs 4 / 8 / 64 -130 / -168 / -240 us per step.
- Full layers' sparse attention reading `req_to_token` itself: server bs 4 / 8 / 16 -62 / -90 / -160 us per step.
- The MoE all-reduce polling its block counters together (`RBLK_PAR`), W13 chunk halves double-buffered (`W13DB`), W2 items of
  128 rows (`W2R`), q_absorb polling together (`QA_POLLALL`): 1-10 us per layer pair each.
